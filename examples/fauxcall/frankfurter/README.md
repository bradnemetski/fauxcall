# Frankfurter API: a FauxCall fake

A high-fidelity fake of **Frankfurter API** (https://api.frankfurter.dev), generated with
[FauxCall](https://github.com/bradnemetski/fauxcall) from https://api.frankfurter.dev/v1/openapi.json. Agents talk to it exactly
like the real API: same paths, parameters, responses and errors,
consistent data across endpoints, real-world timing, and repeatable state.

## Run it

```bash
uv run fauxcall-frankfurter            # http://127.0.0.1:8701
uvx fauxcall up frankfurter            # same, from the workspace root
```

Point your agent at `http://127.0.0.1:8701` instead of
`https://api.frankfurter.dev`.

## Control it during evaluations

Every fake has an admin API under `/__fauxcall` (send `X-Fauxcall-Session: <id>` to isolate parallel runs):

| call | what it does |
|---|---|
| `GET /__fauxcall/health` | status, clock, sessions |
| `POST /__fauxcall/reset` | back to the recorded state (`{"session": "..."}` for one session) |
| `POST /__fauxcall/clock` | `{"op": "freeze"}`, `{"op": "travel", "at": "2026-01-05T15:30:00Z"}`, `{"op": "scale", "rate": 60}`, `{"op": "real"}` |
| `GET /__fauxcall/journal` | every call the agent made (filter by `session`, `endpoint`, `since`) |
| `PUT /__fauxcall/faults` | inject errors, timeouts, delays, disconnects, 429s |
| `PUT /__fauxcall/auth/users` | allowed / denied / expired users |

Settings come from `FAUXCALL_*` variables, `.env` and `fauxcall.toml` (e.g. `FAUXCALL_FAST=1` turns off
latency and rate-limit emulation).

## Known limitations

- **Rates stop moving after 2026-10-09** (the last recorded ECB fixing). Later fixings on the fake clock
  keep real dates (16:30 Berlin, TARGET days) but repeat the 2026-10-09 rates. For trend or
  day-over-day tasks, travel the clock to a date on or before 2026-10-09.
- The real `/latest` rollover sits behind a Cloudflare cache (`max-age=86400`) and was never observed
  on a weekday; the fake switches at exactly 16:30 Berlin.
- POST/PUT/PATCH/DELETE are served like GET, as the source does. This is not verified live.
- `last-modified` is not sent on the index pages or `openapi.json`. The ETag is always weak, as seen
  through Cloudflare gzip.
- TARGET holidays after 2026 are computed, not recorded (they are listed up to 2040).

## What's inside

| path | what |
|---|---|
| `data/model.json` | everything the fake knows: endpoints, field time policies, relations, errors, jobs |
| `data/recordings/` | the real exchanges it was built from (secrets redacted, personal data pseudonymized) |
| `data/world/` | the consistent dataset it serves |
| `src/fauxcall_frankfurter/handlers.py` | custom behavior (yours to edit) |
| `src/fauxcall_frankfurter/routes.py` | one route per real endpoint (regenerated by `fauxcall scaffold`) |
| `tests/` | unit tests, recorded-request replays and end-to-end scenarios (yours to extend) |

## Test it

```bash
uv run pytest                                   # unit + offline end-to-end (no network)
uv run pytest tests/e2e --target=parity         # compare with the real API (needs .env)
```

Endpoints: 9.
