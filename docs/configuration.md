# Configuration

FauxCall has two sets of settings: those of a **generated fake** (how it serves) and those of the
**`fauxcall` command** (how it builds and records). Both are read the same way.

## Where settings come from

Highest priority first:

1. Environment variables: `FAUXCALL_<SETTING>` (nested settings use `__`: `FAUXCALL_CLOCK__MODE`)
2. The `.env` file in the working directory
3. `fauxcall.toml` in the working directory
4. Defaults

Lists and nested objects can be given as JSON in environment variables:

```bash
FAUXCALL_FAST=1
FAUXCALL_CLOCK__MODE=frozen
FAUXCALL_CLOCK__AT=2026-10-13T14:30:00Z
FAUXCALL_FAULTS='[{"endpoint": "GET /v1/quotes/*", "kind": "rate_limit", "probability": 0.1}]'
```

The same in `fauxcall.toml`:

```toml
fast = true

[clock]
mode = "frozen"
at = "2026-10-13T14:30:00Z"

[[faults]]
endpoint = "GET /v1/quotes/*"
kind = "rate_limit"
probability = 0.1
```

Credentials belong in `.env`, which is git-ignored. `fauxcall init` creates it with owner-only
permissions. FauxCall never prints credential values: `fauxcall env check <name>` only reports
which are set.

## Fake settings

| Setting | Default | What it does |
|---|---|---|
| `host`, `port` | `127.0.0.1`, `8000` | Where the fake listens (`port` is assigned per fake when scaffolding) |
| `fast` | `false` | Switch off latency and rate-limit emulation |
| `latency` | `true` | Emulate the recorded response times |
| `rate_limits` | `true` | Emulate the real rate limits, `429`s and headers included |
| `seed` | `0` | Seed for everything random (ids, faults, job outcomes): same calls, same answers |
| `clock` | real time | See [Clock](#clock) |
| `persist_state` | `false` | Keep changes made through the API across restarts (in `state_dir`) |
| `state_dir` | `data/state` | Where persisted state lives |
| `session_header` | `X-Fauxcall-Session` | Header that gives a caller its own state and clock |
| `admin_prefix` | `/__fauxcall` | Where the admin API is mounted |
| `admin_token` | none | When set, the admin API requires `X-Fauxcall-Admin-Token` |
| `journal_limit` | `10000` | How many calls the journal keeps (`0` turns it off) |
| `auth` | anyone with a well-formed credential | See [Users and auth](#users-and-auth) |
| `faults` | none | See [Faults](#faults) |
| `jev` | on when a key is set | See [Jev](#jev) |
| `typesafe_api_key` | none | Jev key; also read from `TYPESAFE_API_KEY` |
| `real` | from the model | The real API, for parity tests. See [The real API](#the-real-api) |
| `pseudonym_key` | generated by `init` | Key for consistent pseudonyms of personal data (keep it secret) |
| `log_level`, `log_format` | `INFO`, `auto` | See [Logging](#logging) |
| `data_dir` | `data` | The fake's model, recordings and world |

### Clock

| Setting | Default | What it does |
|---|---|---|
| `clock.mode` | `real` | `real`, `frozen`, `offset` (time travel) or `scaled` (faster or slower time) |
| `clock.at` | none | The instant for `frozen`; the start for `offset` and `scaled` |
| `clock.offset_seconds` | `0` | Shift for `offset` |
| `clock.rate` | `1` | Simulated seconds per real second for `scaled` |

The clock can also be changed while the fake runs, per session: `POST /__fauxcall/clock`.

### Users and auth

The fake checks credentials the way the real API does: the same header, query parameter or cookie
names, and the same error responses. Which credentials it accepts is up to you:

| Setting | Default | What it does |
|---|---|---|
| `auth.mode` | `any` | `any`: any well-formed credential works unless it belongs to a user configured otherwise. `allowlist`: only configured users. `off`: no checks |
| `auth.users` | none | Known users: `name`, `status` (`allowed`, `denied`, `expired`, `insufficient_scope`), `api_key`, `bearer_token`, `username`/`password`, `scopes` |
| `auth.default_user` | none | Who the built-in OAuth server signs in when the client gives no `login_hint` |

```toml
[auth]
mode = "allowlist"
default_user = "alice"

[[auth.users]]
name = "alice"
api_key = "test-key-alice"

[[auth.users]]
name = "mallory"
status = "denied"
api_key = "test-key-mallory"
```

Users can also be replaced at runtime: `PUT /__fauxcall/auth/users`. OAuth tokens issued by a fake's
built-in authorization server are only accepted until they expire or are revoked.

### Faults

Each rule injects a failure into matching calls. Rules are seeded, so a run is repeatable.

| Field | Default | What it does |
|---|---|---|
| `endpoint` | `*` | Glob on the endpoint id: `GET /pets/*`, `MCP tools/call:*` |
| `kind` | `error` | `error`, `timeout`, `delay`, `disconnect` or `rate_limit` |
| `probability` | `1.0` | Share of matching calls affected |
| `status` | `500` | Status for `error` |
| `error_template` | none | Answer with one of the real API's recorded errors instead |
| `delay_ms` | `0` | For `delay` and `timeout` |
| `first_n`, `every_nth` | none | Only the first N, or every Nth, matching call |
| `session` | none | Only calls from this session |

Faults can be replaced while the fake runs: `PUT /__fauxcall/faults`.

### The real API

Used by parity tests (`pytest --target parity`) and by `fauxcall record`:

| Setting | What it does |
|---|---|
| `real.base_url` | The real service, if different from the one in the model |
| `real.headers` | Headers to send, e.g. `FAUXCALL_REAL__HEADERS='{"Authorization": "Bearer …"}'` |
| `real.query` | Query parameters to send, e.g. an `api_key` |
| `real.timeout_seconds` | Per-request timeout (default 30) |

### Jev

| Setting | Default | What it does |
|---|---|---|
| `jev.enabled` | `true` | Use Jev when a key is set |
| `jev.model` | `jev-1.13.0` | Model version (pinned so answers stay stable) |
| `jev.timeout_seconds` | `5` | After this, the deterministic fallback answers |
| `jev.min_confidence` | `0.5` | Below this, the deterministic fallback answers |

Answers are cached in `data/jev-cache.jsonl`. Commit it, and the fake answers the same way without
a key.

### Logging

Logs are structured ([structlog](https://www.structlog.org)) and carry the request id, session and
endpoint of the call being answered. Libraries' logs (uvicorn and others) go through the same
pipeline.

| Setting | Default | What it does |
|---|---|---|
| `log_level` | `INFO` (fakes), `WARNING` (CLI) | `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL` |
| `log_format` | `auto` | `console` (readable), `json` (one object per line) or `auto` (console in a terminal, else JSON) |

Credentials are redacted from logs, even inside nested values.

## Command settings

| Setting | Default | What it does |
|---|---|---|
| `workspace` | `fauxcall` | Where fakes are generated |
| `record_rps` | `2` | Most requests per second sent to a real API while recording |
| `record_max_calls` | `2000` | Most requests per recording run |
| `request_timeout_seconds` | `30` | Timeout for requests to real services |
| `user_agent` | `fauxcall/<version> (+https://github.com/bradnemetski/fauxcall)` | Sent to real services |
| `source` | this version | Where generated fakes get FauxCall from: a version specifier, or a local checkout path for development |
| `typesafe_api_key` | none | Jev key; also read from `TYPESAFE_API_KEY` |
| `log_level`, `log_format` | `WARNING`, `auto` | As for fakes |

## The admin API

Every fake serves it under `admin_prefix` (default `/__fauxcall`). Calls take the caller's session
from the session header unless a `session` is given.

| Call | What it does |
|---|---|
| `GET /health` | Status, version, sessions, the clock, whether Jev is active |
| `POST /reset` | Back to the recorded state: `{}` for everything, `{"session": "run-1"}` for one, `"journal": true` to clear the journal too |
| `GET /sessions` | Sessions with their own state |
| `GET /clock` · `POST /clock` | Read or change the clock: `{"op": "freeze"}`, `{"op": "advance", "seconds": 60}`, `{"op": "travel", "at": "…"}`, `{"op": "offset", "seconds": -3600}`, `{"op": "scale", "rate": 60}`, `{"op": "real"}` |
| `GET /journal` · `DELETE /journal` | Calls made, oldest first; filter with `session`, `endpoint`, `method`, `path_prefix`, `since`, `limit` |
| `GET /faults` · `PUT /faults` · `DELETE /faults` | Fault rules |
| `PUT /auth/users` | Replace the known users |
| `GET /world/{collection}` | The records a session sees |
| `GET /snapshot` · `POST /restore` | Save and restore a session's state |
| `GET /model` | The model the fake serves |
